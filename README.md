# Bakerz Bite - Bakery & Cafe Website

A responsive, modern bakery and cafe website built with HTML, CSS, Bootstrap 5, JavaScript, and jQuery. This is a front-end eProject demonstrating a full-featured bakery website with product catalog, cart functionality, and order flow.

## Features

- **Home Page** - Hero section, featured products, categories, and promotional banners
- **Product Catalog** - Browse products by category (Cakes, Pastries, Cookies, Pies, Desserts, Cupcakes, Breads, Beverages, Seasonal, Merchandise, Donuts, Savoury)
- **Product Details** - Modal with product information, ingredients, allergens, and add to cart
- **Shopping Cart** - Add/remove items, update quantities, view order summary
- **Order Flow** - Buy Now from cart places all items in one order with receipt generation
- **Custom Cake Builder** - Customize cakes with different options
- **Offers & Promotions** - Special deals and offers
- **Gallery** - Photo gallery of products and bakery
- **Feedback & Reviews** - Customer feedback system
- **Contact & FAQ** - Contact form and frequently asked questions
- **Responsive Design** - Works on desktop, tablet, and mobile devices

## Tech Stack

- HTML5
- CSS3 (Custom CSS with animations)
- Bootstrap 5.3.3
- JavaScript (Vanilla JS)
- jQuery 3.7.1
- Bootstrap Icons

## Getting Started

1. Clone the repository or download the files
2. Open `index.html` in your web browser
3. No build process or server required - it's a static website

## Demo

This is a front-end demonstration project. All orders, payments, and data are stored locally in the browser using localStorage. No backend server is required.
